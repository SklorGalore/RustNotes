\section{Rust Basics}

\subsection{Installing Rust}

Install\index{installation} Rust from the \href{https://www.rust-lang.org/tools/install}{Rust website}.
Once you have rust installed, check that the Rust compiler is set up correctly by running
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{console}
$ rustc --version
\end{minted}
Rust can be updated using rustup\index{rustup}, the included tool chain for installing and maintaining Rust.
The version of rustup can be checked in a similar matter.
Rust can be updated via rustup by running
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{console}
$ rustup --version
$ rustup update
\end{minted}
\subsection{Cargo Basics}

Rust runs typically from a main function\index{functions!main} created by initializing the project using cargo.
Initialize a project\index{projects} using cargo \index{cargo!initialize}
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{console}
$ cargo new project_name
\end{minted}
If the directory already exists, you can build a project in that directory using
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{console}
$ cargo init
\end{minted}
You can add dependencies, like external libraries from \href{crates.io}{crates.io}, by running
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{console}
$ cargo add package_name
\end{minted}
Finally, when you're ready, you can build your project for debugging or release using cargo as well via
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{console}
$ cargo build # compiles for debug by default
$ cargo build --release # for building using the release profile
$ cargo run # compiles for debug and runs the executable
$ cargo run --release # compiles and runs the release profile executable
\end{minted}
Additionally, you can always compile your Rust script using the Rust compiler itself and then running the produced executable
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{console}
$ rustc main.rs # compile
$ ./program_name # run the produced executable
\end{minted}
\subsection{Basic Setup}

Typical Rust programs will contain the following code snippet within \code{main.rs} by default
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
fn main(){
    println!("Hello, world!")
}
\end{minted}
The code contained in the main function is what gets compiled and called by the typical Rust compilation actions.
Note that the default function setup contains the macro \code{println!} which prints the string literal \code{"Hello, world!"} to the console.
We know this is a macro because the standard naming scheme for macros in Rust is to leave an "!" at the end of a function name.
\subsection{Including Libraries}

Certain libraries are packaged with Rust, known as the \textit{standard library}, shortened to \textit{std}.
These packages do not need to be included as dependencies via cargo and can be brought into your code via the following syntax
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
use std::io
\end{minted}
The double colon '::' is similar to the dot '.' notation from other languages where the above brings in the \code{io} library from the standard library.
\subsection{Variable Declarations}

New variables are declared using \code{let}.
Variables are \emph{immutable} by default and must be declared as \textit{mutable} using the keyword \code{mut} during the variable declaration
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
let x = 5; // x is an immutable variable
let mut y = 6; // y is a mutable variable
\end{minted}
You can, and should, annotate the type of a variable when declaring it like this
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
let x: i32 = 297;
let y: &str = "hello"
\end{minted}
Note that \code{\&str} is a reference to the string type which will be touched on later.
\subsection{User Input}

Input from the terminal can be obtained using the standard library's \code{io::stdin()} method.
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
io::stdin()
    .read_line(&mut guess);
\end{minted}
Where a mutable reference to the variable "guess" is passed to the standard io method allowing it to pass the terminal input to the location in memory where the variable guess is stored.
This reference must be mutable because we are changing the value stored at that location.
We can add the \code{except} method to this call and add a response in the case that the method fails.
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
io::stdin()
    .read_line(&mut guess)
    .except("Failed to read input");
\end{minted}
\section{Variables and Typing}

Constants\index{constants} are declared with the keyword \code{const} and like most variables are immutable.
The difference is that constants can \emph{never} be made mutable.
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
const varname = 5;
\end{minted}
Variables can also be reassigned via \emph{shadowing}\index{shadowing} where an immutable variable has its value reassigned by re-declaring it using the current value with some modification added
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
let x = 5 // x is an immutable variable
let x += 5 // x now equals 10! We have changed an immutable variable
\end{minted}
Note that this allows us to both change a variables value \textbf{and} its type because we are effectively creating a new variable with the same name.
\section{Control Flow}
Control flow is a basic and essential part of code which allows for controlling the path a written section of code takes based on designated inputs and information.
Looping and conditional execution are two common examples of control flow.
\subsection{Loop}

Basic looping can be accomplished with the \code{loop} keyword which establishes a loop that continues until \code{break} is run
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
loop 'loopname { 
    println!("Looping!");
    break 'loopname
}
\end{minted}
Note that loops can also be named and continued or broken by their name.
This is especially useful for controlling nested loops.

\subsection{Scalar Data Types}

Scalar data types contain data of only one type and fall into one of the following four categories
\begin{itemize}
	\item Integers
	\item Floating Point Numbers
	\item Booleans
	\item Chars
\end{itemize}
\subsubsection{Integers}

Integers are whole numbers without decimal components and can be defined based on their size
\begin{table}[h]
	\centering
	\caption{Integer Types in Rust}
	\label{tab:int-types}
	\begin{tabular}{@{}llll@{}}
		\toprule
		Length                 & Signed & Unsigned & Size of Values                  \\ \midrule
		8-bit                  & i8     & u8       & $2^8=256$                        \\
		16-bit                 & i16    & u16      & $2^{16}=65,536$                  \\
		32-bit                 & i32    & u32      & $2^{32}\cong4.294\times10^9$   \\
		64-bit                 & i64    & u64      & $2^{64}\cong18.446\times10^{18}$ \\
		128-bit                & i128   & u128     & $2^{128}\cong3.40\times10^{38}$  \\
		Architecture-dependent & isize  & usize    & See above                        \\ \bottomrule
	\end{tabular}
\end{table}
Numeric literals that can be interpreted as multiple types can be specified by annotating them within their use
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
let x: i32 = 23 + 16u16
\end{minted}
Numeric literals can be specified in any of the following formats
\begin{table}[h]
	\centering
	\caption{Integer Literals in Rust}
	\label{tab:my-table}
	\begin{tabular}{@{}ll@{}}
		\toprule
		Number Literal & Example      \\ \midrule
		Decimal        & 98\_222      \\
		Hex            & 0xff         \\
		Octal          & 0o77         \\
		Binary         & 0b1111\_0000 \\
		Byte (u8 only) & b'A'         \\ \bottomrule
	\end{tabular}
\end{table}
If you're unsure what to use, Rust's default integer type is i32.
\subsubsection{Floating Points}

Floating point numbers can be specified as \code{f32} or \code{f64} and are represented according to IEEE-754.
\subsubsection{Booleans}

Booleans are values that can either be true or false, and are annotated as \code{bool}.
Note that Rust, unlike some other languages, will not interpret any non boolean type values as a bool.
If the condition of non boolean type data is checked, it will fail.
\subsubsection{Chars}

Chars are a 4-byte type representing a Unicode scalar value.
\subsection{Compound Types}

Compound types are data types which themselves may contain multiple different pieces of data which may be different types of their own
\subsubsection{Tuples}

Tuples are types of fixed length which may contain multiple different data types.
Note that once a tuple is declared, its length may not be increased or decreased, though it may be de-structured into individual pieces
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
// declaring a tuple of different types
let tup: (i32, f64, u8) = (500, 6.4, 1);

// de-structuring a tuple
let (x, y, z) = tup;
\end{minted}
\pagebreak
You may also access individual elements of a tuple using dot notation
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
	// declaring a tuple of different types
	let tup: (i32, f64, u8) = (500, 6.4, 1);
	
	// retrieving the first value from a tuple
	let x = tup.0;
\end{minted}
Empty tuples with no type have their own name and type, \emph{unit}, written as $()$.
Any expression which does not inherently return a value will return unit.
\subsubsection{Arrays}

Arrays hold collections of multiple items which have the \emph{same} type.
Like tuples, arrays have a fixed length.
Arrays are declared with brackets and only need one type declaration along with their length.
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
// declaring an array of type i32 and length 5
let a: [i32; 5] = [1, 2, 3, 4, 5];
\end{minted}
Array values are accessed using bracket notation
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
let first = a[0];
let second = a[1];
\end{minted}
\section{Functions}

Functions are the main way of executing code in Rust and are declared with the \code{fn} keyword.
The usual entry point of a Rust program is the \code{main} function that is created with a new project by default
\begin{minted}[linenos, style=gruvbox-dark, bgcolor=darkgray]{rust}
fn main() {

}

fn secondary(x: i32) -> i32 {
    x + 23
}
\end{minted}
Functions can take inputs specified during the function signature of the annotated type and return a value of the specified type at the end of the function signature.
Note that above, the value $x+23$ is returned because it is the last expression in the function. A value elsewhere in the function can be returned using the keyword \code{return} followed by an expression.

This brings up the concept of expressions\index{expressions} versus statements\index{statements}.
The difference between the two is that expressions return a value while statements do not.
Statements are terminated with a semicolon, while expressions are not.
